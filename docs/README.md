# docs

Background and decisions that are not derivable from the code. `CLAUDE.md` carries the commands and
the working rules; everything about how the app is built lives here, once.

- [architecture.md](architecture.md) - the pipeline, uploads, push, the Mode Lab, Practice, Beat, the
  demo, the interpretation, operational guards, client conventions and infrastructure.
- [ui-rules.md](ui-rules.md) - the look-and-layout rules and the rule every effect is held to.
- [removed.md](removed.md) - what existed and was taken out, with the reason. Read it before
  proposing a feature: several obvious ones are on it.

Nothing here should describe code that does not exist.
